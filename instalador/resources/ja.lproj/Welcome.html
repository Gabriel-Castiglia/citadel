Citadel @VERSION@

この Mac 上で Ollama を通じて動く言語モデルのためのチャットアプリです。設定で SSH 経由の別のコンピューターの Ollama を使うことを選ばない限り、書いた内容がコンピューターの外に出ることはありません。

動作環境: Apple シリコン搭載の macOS 14 以降と、少なくとも 1 つのモデルを入れた Ollama:

brew install ollama
brew services start ollama
ollama pull qwen3:8b

Citadel は「アプリケーション」フォルダに入ります。以前のバージョンがある場合は置き換え、会話、ルール、メモリ、設定はそのまま残ります。
