Citadel @VERSION@

A chat app for language models that run on this Mac through Ollama. Nothing you write leaves the computer, unless you choose in Settings to use Ollama on another computer through SSH.

Requirements: macOS 14 or later on Apple silicon, and Ollama with at least one model:

brew install ollama
brew services start ollama
ollama pull qwen3:8b

Citadel goes to the Applications folder. If an earlier version is installed, it is replaced; conversations, rules, memories and settings are kept.
